# coupon-checkout-demo

A tiny checkout pricing module used to demo Coder Agents.

No dependencies beyond Python 3.10+.

## Run the tests

```sh
python3 -m unittest discover -s tests -v
```

## Open bug (from support)

Customers are applying coupon codes that expired weeks ago. Support has seen it with
coupons that expired in an earlier month, for example a September coupon still working
in November.
